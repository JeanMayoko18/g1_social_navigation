# OM integration roadmap

**Status: planned.** The current reference experiment is a social-navigation encounter with the active profile, perception events, interaction decision and navigation outcome recorded.

1. Establish which coordination decisions each social-navigation configuration already makes and which decision an OM should inform.
2. Define the inputs, output message, validity period and consuming node for the first OM. Specify how the coordinator handles a late or unavailable output.
3. Replay recorded encounters and compare the coordinator’s decisions with the reference run before enabling the integration in a physical trial.

The integration guide can name the package, launch argument and supported deployments once these interfaces have been implemented and exercised.
